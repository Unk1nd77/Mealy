# Mealy

Mealy — приложение в духе **Apple Health / Apple Fitness** для питания, дневного ритма и планирования еды.

Идея простая: пользователь не должен жить в таблицах, чатах и калькуляторах КБЖУ. Mealy собирает цель, ограничения и привычки, а затем превращает их в понятный план: что есть сегодня, что приготовить на неделю, что купить и что добавить в календарь.

> Mealy не заменяет врача или диетолога. Это бытовой health companion для более спокойного и организованного питания.

---

## Концепт

Mealy — не “ещё один калькулятор калорий” и не “чат про рецепты”.

Это персональный экран питания, похожий по ощущению на Apple Health и Apple Fitness:

- **Today** показывает день целиком: ближайший приём пищи, прогресс по калориям, баланс белков/жиров/углеводов и быстрые действия.
- **Plan** собирает неделю без ручного планирования.
- **Recipes** хранят проверенные блюда, из которых можно безопасно строить рацион.
- **Shopping** превращает план в список покупок.
- **Calendar** переносит питание в реальный день пользователя.

Главная эмоция продукта: “у меня всё собрано, понятно и под контролем”.

## Стиль

Визуально Mealy должен быть ближе к Apple Health / Fitness, чем к типичному зелёному ЗОЖ-приложению.

### База

- чистые белые и светло-серые поверхности;
- крупная спокойная типографика;
- много воздуха;
- тёмные summary-блоки для важных состояний;
- минимум декоративного шума;
- карточки как в системных iOS/macOS-приложениях;
- статусные кольца, шкалы и короткие health-сводки.

### Палитра

| Роль | Цвет |
|------|------|
| Фон | `#ffffff` |
| Мягкий фон | `#f5f5f7` |
| Основной текст | `#1d1d1f` |
| Вторичный текст | `#6e6e73` |
| Primary action | `#0066cc` |
| Action на тёмном | `#2997ff` |
| Тёмная поверхность | `#000000` / `#272729` |
| Nutrition / balance | `#30d158` |
| Energy / calories | `#ff9f0a` |
| Progress / activity | `#ff2d55` |
| Warning | `#ff453a` |

Синий остаётся главным цветом действия. Зелёный, оранжевый и розовый работают как health/activity-индикаторы, а не как основная окраска всего интерфейса.

### Не делать

- зелёно-бежевую “эко” тему;
- медицинский интерфейс с тяжёлыми предупреждениями;
- маркетинговый лендинг вместо полезного первого экрана;
- декоративные градиенты и лишние тени;
- интерфейс, который выглядит как таблица калорий.

---

## Что делает продукт

- собирает профиль, цель, активность и ограничения;
- подбирает блюда из каталога;
- генерирует недельный план питания;
- проверяет калории и макронутриенты;
- показывает Today dashboard;
- даёт карточки рецептов;
- собирает список покупок;
- экспортирует план в календарь;
- помогает быстро заменить блюдо, если план не подходит.

---

## Основной сценарий

```text
Анкета
  -> профиль и ограничения
  -> недельный план
  -> Today dashboard
  -> рецепты
  -> покупки
  -> календарь
```

Пользователь должен открывать Mealy не ради “настроек питания”, а ради ответа на простой вопрос:

**что мне есть сегодня и что нужно подготовить дальше?**

---

## Продуктовые экраны

- **Today** — главный экран дня.
- **Week** — план питания на неделю.
- **Recipes** — блюда и детали приготовления.
- **Shopping** — список покупок по плану.
- **Insights** — короткая сводка по балансу и прогрессу.
- **Integrations** — Calendar, PDF, share, clipboard.
- **Profile** — цель, ограничения, аллергии, предпочтения.

## Разработка

Стек: Astro, React, TypeScript, FastAPI, PostgreSQL, Redis, Celery.

Запуск backend:

```bash
docker compose up -d db redis
cd backend
uv sync --dev
uv run alembic upgrade head
uv run python scripts/seed_recipes.py
uv run python scripts/backfill_recipe_embeddings.py
uv run python scripts/seed_demo_user.py
uv run uvicorn app.main:app --reload --port 8000
```

В отдельном терминале запусти worker генерации:

```bash
cd backend
uv run celery -A app.worker.celery_app worker --loglevel=info
```

Запуск frontend:

```bash
cd frontend
cp .env.example .env
npm install
npm run dev
```

Локальный адрес:

```text
http://127.0.0.1:4321
```

Фронт использует backend как единственный источник профиля, плана, рецептов, списка покупок и статуса генерации.

Каталог использует OpenRouter embeddings и PostgreSQL `pgvector`: сначала HNSW
ранжирует рецепты по смысловой близости, затем обязательные фильтры исключают
аллергены, противопоказания и нелюбимые продукты. Проверка полного контура:

```bash
cd backend
uv run python scripts/verify_vector_search.py
```

Административные маршруты `/api/catalog/*` доступны только пользователям, чьи
email перечислены в `ADMIN_EMAILS`.
